# lattice-simd

SIMD vector math for Lattice: dot product, cosine similarity, Euclidean and
Manhattan distance, L2 normalization, and approximate operations over INT8,
INT4 and binary quantized vectors, including tiered storage with prepared
queries.

Kernels cover AVX-512, AVX2+FMA, NEON and WASM SIMD128, with a scalar fallback
for every operation. On x86_64 and aarch64 the kernel is chosen at runtime from
the detected CPU features (`SimdConfig`); on wasm32 it is chosen at compile time
from `target_feature = "simd128"`.

The crate has no internal dependencies. `lattice-embed` re-exports it as
`lattice_embed::simd`, so code written against either path uses the same items.

```rust
use lattice_simd::{cosine_similarity, dot_product, normalize};

let mut a = vec![1.0_f32, 2.0, 3.0];
let b = vec![3.0_f32, 2.0, 1.0];
let dot = dot_product(&a, &b);
let cos = cosine_similarity(&a, &b);
normalize(&mut a);
assert!(dot > 0.0 && cos > 0.0);
```

The SIMD surface is marked unstable. See [docs/simd.md](docs/simd.md) for the
kernel family, dispatch, numerical behaviour and the quantized-vector formats.
