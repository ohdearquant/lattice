# lattice v0.12.1

Patch release. Documentation and package metadata only: no source, dependency or feature changes, so code that compiles against `0.12.0` compiles unchanged and behaves the same.

## Package metadata

- Every crate now carries crates.io keywords and categories (#1936).
- docs.rs builds `lattice-inference` with `f16`, `x86-gemm`, `mixture`, `train-backward` and `wgpu-gpu`, `lattice-embed` with `x86-gemm`, and `lattice-fann` and `lattice-tune` with every feature, so feature-gated public items appear in the hosted documentation (#1936). `metal-gpu` items stay out of it because docs.rs builds on Linux.

## Documentation

- Each crate has its own `CHANGELOG.md`, with the 0.12.0 changes and a summary of earlier releases (#1936).
- README install snippets pin `0.12` (#1936).
- `lattice-inference` documentation builds without rustdoc warnings under the default features and the docs.rs feature set (#1937).
- The `lattice-inference` README's supported architectures table lists EmbeddingGemma 2, Gemma 4 E2B and PaddleOCR-VL / ERNIE-4.5 (#1938).
